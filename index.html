Simulator mode

In simulator mode nothing is sent to the Pico — the 3D arm moves with realistic servo speeds so you can practise safely. Every control (joints, IK, poses, keyboard) works the same as in live mode.

How to calibrate

  1. Switch to Live and connect. Calibrate one servo at a time with the arm supported by hand.
  2. For the two shoulder servos, remove one horn while calibrating the other so they never fight each other.
  3. Use Direct drive to find the servo angle where the joint is at its zero position, then set it as Center.
  4. If a joint moves the wrong way, tick Invert. Shoulder B is normally inverted (mirrored mount).
  5. Set Min/Max angle to the safe mechanical range of that servo — commands are always clamped to it.

Wiring notes

  • Power the servos from a separate 5–6 V supply (≥ 5 A for four MG996R). Never from the Pico's VBUS/3V3.
  • Connect the servo supply ground to a Pico GND pin — the signal needs a common ground.
  • GP23, GP24, GP25 and GP29 are used by the Pico W's wireless chip and can't be assigned.
  • GPn and GPn+16 share one PWM output (e.g. GP0 & GP16), so two servos can't use both.
  • NeoPixels run on PIO, so any free GPIO works. A 330 Ω resistor in the data line is recommended.

Pico W firmware (MicroPython)

Generates a main.py that speaks this page's protocol, using your current pins and LED settings. Copy it and this index.html onto the Pico W (e.g. with Thonny); the Pico will then serve this page at http://<pico-ip>/.

Wi-Fi credentials are only written into the downloaded file; they are not stored by this page. In access-point mode the Pico is at 192.168.4.1. The 3D view loads three.js from the internet; without internet the page falls back to a 2D schematic view.
